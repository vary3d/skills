# Security

Report vulnerabilities by email to **security@vary3d.com**.

Do **not** open a public GitHub issue with a proof of concept, exploit, or reproduction against Vary3D, this repository, or related services.

We will acknowledge reports and handle them privately.

## skills.sh audits

Published skills are scanned by Gen Agent Trust Hub, Socket, and Snyk (Pass / Warn / Fail). This repo avoids W012 (remote instructions as authority) and W013 (`sudo` in `--ensure`). Snyk W011 (third-party page exposure) may still appear if a judge treats Confirm-gated manufacturer pages as exposure; millimetres prefer the user, in-skill tables, then Confirm. That residual is accepted. Do not strip tables or Confirm to chase a Pass badge.
